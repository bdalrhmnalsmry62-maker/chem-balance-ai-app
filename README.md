# وازنها — Chem Balance AI

تطبيق محلي عربي لموازنة المعادلات الكيميائية، مبني باستخدام HTML/CSS/JavaScript وNode.js.

## التشغيل

```bash
npm install
npm start
```

ثم افتح `http://localhost:3000`.

## المزايا

- واجهة عربية RTL واختيار الكلية.
- مركبات بأسماء عربية وإنجليزية وصيغ كيميائية.
- موازنة جبرية محلية مع كشف أخطاء الإدخال.
- شرح مبسط للطرق الجبرية والأكسدة والاختزال وأنصاف التفاعلات.
- معلومات تمهيدية عن طرق استخلاص المركبات.
- مساعد محلي جاهز للتوسعة بمزود ذكاء اصطناعي؛ يتم استدعاؤه من الخادم لحماية مفتاح API.

> تنبيه: النسخة الحالية تعليمية. أضف مفتاح مزود AI ومنطقًا متخصصًا للتفاعلات الأيونية قبل الاعتماد المختبري.

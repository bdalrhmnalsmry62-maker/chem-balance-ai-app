# وازنها - Chem Balance AI

تطبيق ويب عربي متخصص في موازنة المعادلات الكيميائية مع مساعد ذكي تفاعلي.

## المميزات

✅ **4 صفحات منفصلة:**
- الصفحة الرئيسية: ترحيب واختيار الكلية
- قاعدة المركبات: بحث بالعربي والإنجليزي والصيغة
- موازنة المعادلات: حساب جبري مع شرح الخطوات
- المساعد الذكي: محادثة تفاعلية

✅ **تنقل سهل:** شريط تنقل علوي في كل صفحة

✅ **مساعد ذكي:** يجيب على الأسئلة الكيميائية تلقائياً

✅ **موازنة جبرية محلية:** لا تحتاج إنترنت

✅ **واجهة عربية RTL:** تصميم جميل ومتجاوب

## التثبيت والتشغيل

### المتطلبات
- Node.js (الإصدار 18 أو أحدث)
- npm (يأتي مع Node.js)

### الخطوات

1. **استنسخ المستودع:**
```bash
git clone https://github.com/bdalrhmnalsmry62-maker/chem-balance-ai-app.git
cd chem-balance-ai-app
```

2. **ثبت المكتبات:**
```bash
npm install
```

3. **شغّل التطبيق:**
```bash
npm start
```

4. **افتح في المتصفح:**
```
http://localhost:3000
```

## كيفية الاستخدام

### موازنة معادلة
1. انتقل إلى صفحة "الموازنة"
2. اكتب المعادلة بصيغة: `H2 + O2 -> H2O`
3. اضغط "وازن المعادلة"
4. سترى النتيجة والشرح

### البحث عن مركب
1. انتقل إلى صفحة "المركبات"
2. ابحث باسم عربي أو إنجليزي أو صيغة
3. مثال: "الماء" أو "Water" أو "H2O"

### الحوار مع المساعد
1. انتقل إلى صفحة "المساعد الذكي"
2. اكتب سؤالك
3. اضغط "إرسال" أو Enter
4. سيجيب المساعد فوراً

## أمثلة معادلات

- `H2 + O2 -> H2O` (تفاعل الاحتراق)
- `CH4 + O2 -> CO2 + H2O` (احتراق الميثان)
- `Fe + O2 -> Fe2O3` (أكسدة الحديد)
- `KClO3 -> KCl + O2` (تحلل كلورات البوتاسيوم)

## المركبات المتاحة

التطبيق يحتوي على 19 مركب شهير:
- H2 (الهيدروجين)
- O2 (الأكسجين)
- H2O (الماء)
- CO2 (ثاني أكسيد الكربون)
- CH4 (الميثان)
- NH3 (الأمونيا)
- NaCl (كلوريد الصوديوم)
- وغيرها...

## المساعد الذكي

يمكن للمساعد الإجابة عن أسئلة مثل:
- "كيف أوازن المعادلة؟"
- "ما طرق استخلاص المركبات؟"
- "ما الفرق بين التقطير والترشيح؟"
- "ما الكليات المتاحة؟"

### ملاحظة:
المساعد الحالي يعمل بإجابات محلية محددة. لتحويله إلى ChatGPT حقيقي، أضف مفتاح API من OpenAI أو Google Gemini في `server.js`.
